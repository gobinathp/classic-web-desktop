# Scope and roadmap

## Shipped in v0.2

Classic window shell and 38 component exports, modular entry points, native form controls, paginated/sortable tables, modern feedback/navigation/overlays, and a live component studio.

## Candidate enhancements, not shipped or promised

- Controlled desktop layout restoration with schema validation and user-data safeguards.
- Server-driven table sorting/pagination helpers and opt-in large-list virtualization.
- Optional adapters for charts, maps, rich text, calendars, and command palettes.
- Additional browser, screen-reader, touch-device, and real low-memory hardware coverage.
- Further performance profiling and contribution-driven examples.

Keep heavyweight features optional. No automatic analytics, remote asset downloads, app marketplaces, or arbitrary plugin execution in the core. No claim to support every historical browser or every component category. Preserve compact classic styling, safe defaults, and a measurable size budget.
